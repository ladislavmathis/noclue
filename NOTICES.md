The VAD model, worklet, ONNX WASM, fonts and JavaScript are served from the extension
itself. Nothing is loaded from a CDN at runtime. The list is checked against the built bundle
before each release (`docs/RELEASE.md`). The website in `docs/site` uses the same two fonts
under the same licenses (`docs/site/fonts/OFL-*.txt`).

`tests/fixtures/meeting-speech.wav` is a locally generated English test sentence (macOS
`say`, Samantha voice), used only in tests and never shipped.
